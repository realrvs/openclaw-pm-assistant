# Project Management Skill

Используй этот скилл для работы с проектами.

## Данные
Файл с проектами: ~/.openclaw/workspace/data/projects.json

## Как отвечать на запросы

### Статус всех проектов
Когда пользователь спрашивает "Покажи статус проектов" или "Что по проектам?":
1. Прочитай файл projects.json
2. Сформируй ответ в читаемом формате

Пример ответа:
📊 Статус проектов:

**Автоматизация закупок РусГидро**
- Статус: Предварительные испытания
- Команда: 20 чел.
- Технологии: Vue.js 3, Python FastAPI, PostgreSQL

### Риски
Когда спрашивают "Какие риски?":
1. Прочитай файл projects.json
2. Выведи риски по каждому проекту

### Детали проекта
Когда спрашивают "Расскажи про проект РУС" или "Детали по проекту ВТБ":
1. Найди проект по id (RUS, DIT, VTB)
2. Выведи полную информацию

## Важно
- Всегда читай файл projects.json перед ответом
- Давай структурированные, читаемые ответы
- Если данных нет, скажи об этом честно
