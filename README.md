# OpenClaw AI Project Management Assistant

**Phase 0: Infrastructure Setup**

AI-ассистент для управления ИТ-проектами на базе OpenClaw и YandexGPT.

## 🚀 Быстрый старт

### Требования
- OpenClaw 2026.7.1+
- Python 3.12+
- Node.js 24+

### Установка
```bash
# Клонировать репозиторий
git clone https://github.com/realrvs/openclaw-pm-assistant.git
cd openclaw-pm-assistant

# Настроить OpenClaw
openclaw onboard --mode local
